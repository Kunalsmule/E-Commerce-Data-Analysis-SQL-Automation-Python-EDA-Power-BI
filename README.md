# E-Commerce-Data-Analysis-SQL-Automation-Python-EDA-Power-BI

Project Overview

Developed an end to end e-commerce analytics solution to transform transactional data into actionable business insights. Leveraged SQL Server, Python, and Power BI to analyze sales, customer behaviour, product and seller performance, delivery operations, and customer satisfaction.

Technology Stack

SQL Server: Data exploration, transformation, advanced queries, business KPIs, cohort analysis, and SQL automation.

Python: Pandas, NumPy, Matplotlib, Seaborn, and SciPy for EDA, RFM segmentation, and statistical analysis.

Power BI: Data modelling, DAX measures, KPI reporting, and interactive dashboards.

SQL Server Agent: Automated monthly SQL job execution and recurring business reporting.

Key Analytical Work

1. SQL - Business Intelligence & Automation

Performed data exploration, cleaning, joins, aggregations, CTEs, and window function analysis.

Developed business queries for sales, orders, customers, products, and sellers.

Conducted cohort and customer retention analysis.

Implemented monthly automated reporting using SQL Server Agent, scheduling SQL jobs at the beginning of each month.

2. Python – Customer & Operational Analytics

Performed data cleaning, EDA, and feature preparation.

Implemented RFM based customer segmentation.

Compared one time and repeat customers based on purchase frequency and monetary value.

Analyzed delivery performance against customer review scores.

Evaluated merchandise value across product categories and assessed category level sample sizes.

3. Statistical Analysis

Applied the Mann Whitney U test to compare monetary value between one time and repeat customers.

Used rank biserial correlation to measure effect size.

Compared average review scores between late and on time deliveries.

Evaluated category level order counts, mean values, and median values for reliable comparisons.

4. Power BI – Management Reporting

Developed interactive dashboards covering business KPIs, sales, customer behaviour, product categories, delivery performance, and customer satisfaction.

Designed management level reporting to support performance monitoring and business decisions.
